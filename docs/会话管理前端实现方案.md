# 会话管理前端实现方案

## Context

AI 助手页面目前只有本地聊天功能，没有会话持久化。后端已提供完整的会话管理 API（CRUD + 改造后的 query 接口），前端需要对接这些 API，实现：会话列表加载、新建/切换/删除/重命名会话、SSE 流式问答中携带 `conversation_id` 并处理新的 `conversation` 事件。

## 修改文件（4个）

### 1. `src/apis/rag.js` — 添加 5 个会话 API 函数

在文件末尾追加，复用已有 `ragFetch`：

```js
// --- 会话管理 ---

export const createConversation = (title = '新对话') =>
  ragFetch('/api/v1/rag/conversations', {
    method: 'POST',
    body: JSON.stringify({ title }),
  });

export const getConversations = () =>
  ragFetch('/api/v1/rag/conversations');

export const getConversationMessages = (convId) =>
  ragFetch(`/api/v1/rag/conversations/${convId}/messages`);

export const updateConversation = (convId, title) =>
  ragFetch(`/api/v1/rag/conversations/${convId}`, {
    method: 'PATCH',
    body: JSON.stringify({ title }),
  });

export const deleteConversation = (convId) =>
  ragFetch(`/api/v1/rag/conversations/${convId}`, {
    method: 'DELETE',
  });
```

### 2. `src/views/AiAssistant/index.jsx` — 核心状态与逻辑

**新增状态：**
- `conversations` — 会话列表数组
- `currentConversationId` — 当前活跃会话 ID

**新增/修改函数：**

| 函数 | 作用 |
|---|---|
| `loadConversations()` | 页面加载时调用 `getConversations()` 填充列表 |
| `handleNewConversation()` | 调用 `createConversation()`，更新列表和当前 ID |
| `handleSwitchConversation(convId)` | 调用 `getConversationMessages(convId)`，映射 API 消息格式到本地 `type: 'Q'/'A'` |
| `handleDeleteConversation(convId)` | 调用 `deleteConversation(convId)`，若删除当前会话则重置 |
| `handleRenameConversation(convId, title)` | 调用 `updateConversation(convId, title)` |

**`handleSend()` 修改：**
- body 添加 `conversation_id`（当 `currentConversationId` 有值时）
- SSE 解析新增 `conversation` 事件处理（当后端自动创建会话时保存 ID 并更新列表）
- 流结束后自动重命名（标题为 "新对话" 时，用首条问题前 20 字替换）
- 用 `resolvedConvId` 局部变量追踪 SSE 中设置的会话 ID，避免闭包过时问题

**新增 props 传递给 AssistantSidebar：**
`conversations`, `currentConversationId`, `onSwitchConversation`, `onDeleteConversation`, `onRenameConversation`

### 3. `src/views/AiAssistant/AssistantSidebar.jsx` — 真实会话列表 UI

- 新增 props：`conversations`, `currentConversationId`, `onSwitchConversation`, `onDeleteConversation`, `onRenameConversation`
- 新增 `ConversationItem` 子组件（`React.memo`）：
  - 点击切换会话
  - 悬停显示重命名（inline Input）和删除（Popconfirm 确认）按钮
  - `EditOutlined` / `DeleteOutlined` 图标按钮
- 将硬编码的 "当前对话" 替换为从 `conversations` 渲染的列表
- 空列表显示 "暂无对话"

## 不修改的文件

- `ChatArea.jsx` — 已通过 props 渲染消息，无需改动
- `src/store/` — 会话状态用本地 state 管理，不增加 Redux slice

## 实施顺序

1. `src/apis/rag.js`（API 基础）
2. `AssistantSidebar.module.css`（样式）
3. `AssistantSidebar.jsx`（UI 组件）
4. `index.jsx`（主逻辑，最后整合）

## 验证

1. `pnpm dev` 启动开发服务器
2. 进入 `/ai-assistant` 页面，侧边栏应加载会话列表
3. 点击 "新建对话" → 调用 API 创建，列表更新
4. 输入问题发送 → SSE 流式正常，检查 Network 中 body 包含 `conversation_id`，侧边栏标题自动更新
5. 切换到另一个会话 → 加载历史消息
6. 悬停会话项 → 显示编辑/删除按钮
7. 重命名 → inline 编辑后调用 API
8. 删除 → Popconfirm 确认后删除，若删除当前会话则重置
