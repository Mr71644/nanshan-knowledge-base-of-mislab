# 批量删除文件功能 — 实现方案

## 一、需求背景

当前 FileList 页面只支持通过右侧菜单逐个删除文件/文件夹/文本/Excel，效率较低。需要在文件列表中增加批量选择和批量删除能力，允许用户一次性勾选多个项目并集中删除。

后端已提供通用批量删除接口，支持所有资源类型。

---

## 二、后端接口

```
DELETE /home/delete/batch
Content-Type: application/json
```

请求体：

```json
{
  "items": [
    { "id": 1, "status": 1 },
    { "id": 2, "status": 2 },
    { "id": 3, "status": 3 },
    { "id": 4, "status": 4 }
  ]
}
```

- `items` 不能为空，每项由 `id` + `status` 唯一定位资源
- `status` 含义：1=文本、2=文件夹、3=Excel、4=普通文件
- 成功返回 `{ "code": 200, "data": N }`，N 为删除数量

## 四、具体实现

### 4.1 API 层 — `src/apis/delete.js`

新增导出函数：

```js
const delBatch = (items) => {
    return request({
        url: '/home/delete/batch',
        method: 'DELETE',
        data: { items }
    })
}
```

### 4.2 组件层 — `src/views/FileList/index.jsx`

#### 新增状态

```js
const [selectedRowKeys, setSelectedRowKeys] = useState([])
const [selectedRows, setSelectedRows] = useState([])
```

#### Table 添加行选择

在 `<Table>` 组件上添加 `rowSelection` 属性，启用复选框列：

```jsx
<Table
    rowSelection={{
        type: 'checkbox',
        selectedRowKeys,
        onChange: (keys, rows) => {
            setSelectedRowKeys(keys)
            setSelectedRows(rows)
        },
    }}
    // ...其他属性不变
/>
```

同时修改 `onRow` 的 `onClick`，点击复选框时不触发行跳转。

#### 批量操作栏

在 `<Table>` 上方条件渲染一个操作栏，仅当有选中项时显示：

```jsx
{selectedRowKeys.length > 0 && (
    <div className={style.batchBar}>
        <span className={style.batchText}>
            已选择 {selectedRowKeys.length} 项
        </span>
        <div className={style.batchActions}>
            <Button onClick={clearSelection}>取消选择</Button>
            <Button danger onClick={handleBatchDelete}>移入回收站</Button>
        </div>
    </div>
)}
```

#### 批量删除处理函数

```js
const handleBatchDelete = () => {
    Modal.confirm({
        title: '确认删除',
        content: `确定将选中的 ${selectedRows.length} 项移入回收站吗？`,
        okText: '确认',
        cancelText: '取消',
        onOk: async () => {
            try {
                setLoading(true)
                const items = selectedRows.map(r => ({ id: r.id, status: r.status }))
                await delBatch(items)
                clearSelection()
                refreshUrl()
            } catch (e) {
                error({ content: '批量删除失败' })
            }
            // 刷新列表
            if (param.id === undefined) getList()
            else getList(param.id)
        }
    })
}

const clearSelection = () => {
    setSelectedRowKeys([])
    setSelectedRows([])
}
```

#### 导入变更

- 从 `@/apis/delete` 新增导入 `delBatch`
- `Modal` 已在现有导入中

## 五、交互流程

1. 用户在文件列表左侧勾选一个或多个项目
2. 表格上方出现蓝色/灰色批量操作栏，显示"已选择 N 项"
3. 用户点击"移入回收站"按钮
4. 弹出确认对话框，显示选中数量
5. 用户确认后调用后端接口，成功后清空选择、刷新列表
6. 用户也可点击"取消选择"清除所有勾选
