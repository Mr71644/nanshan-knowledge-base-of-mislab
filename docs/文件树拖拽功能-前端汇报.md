# 文件树拖拽排序与移动功能 — 前端汇报

## 一、功能概述

在左侧文件树中实现了鼠标拖拽操作，支持以下两种交互：

| 功能 | 说明 |
|------|------|
| 同层排序 | 在同一文件夹内，拖拽文件/文件夹调整显示顺序 |
| 跨层移动 | 将文件/文件夹从一个文件夹拖拽到另一个文件夹中 |

## 二、技术方案

### 2.1 组件升级

将侧边栏从 Ant Design `Menu`（导航组件）升级为 `Tree`（树形组件），获得以下能力：

- **原生拖拽支持**：`Tree` 组件内置 `draggable`、`allowDrop`、`onDrop`，无需引入第三方拖拽库
- **更灵活的节点渲染**：支持自定义图标、展开箭头、节点内容
- **与项目现有架构一致**：项目中权限管理、Excel 文件选择等模块已在使用 `Tree` 组件

### 2.2 拖拽交互设计

**同层排序**：用户拖拽节点到同级节点之间的间隙，松手即完成排序。

**跨层移动（三种方式）**：
1. 拖拽节点**放到文件夹上** → 节点移入该文件夹（排在末尾）
2. 拖拽节点放到另一层级的**间隙中** → 节点移到目标层级
3. 拖拽到**根目录层级** → 节点移出文件夹到最外层

**安全限制**：
- 不允许将文件夹拖入自身的子文件夹（防止循环引用）
- 不允许将节点拖到非文件夹类型（文档、Excel、文件）上

### 2.3 用户体验优化

| 策略 | 说明 |
|------|------|
| 乐观更新 | 拖拽松手后立即更新界面，用户无感知延迟 |
| 后台持久化 | 界面更新后异步调用后端接口保存，不阻塞操作 |
| 失败回滚 | 接口调用失败时自动恢复原始顺序并提示用户 |
| 视觉反馈 | 拖拽时显示可放置区域高亮，不可放置区域无指示器 |

## 四、功能演示要点

1. 打开系统，左侧文件树正常展示
2. 同层内拖拽文件/文件夹，顺序即时变化
3. 拖拽文件到文件夹上，文件移入文件夹
4. 拖拽文件夹到另一个文件夹，整棵子树移动
5. 刷新页面后，所有操作结果保持
