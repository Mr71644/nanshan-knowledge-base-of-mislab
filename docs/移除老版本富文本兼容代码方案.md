# 移除老版本富文本兼容代码方案

## 背景

项目已从 Quill 富文本编辑器完全迁移到 Tiptap Markdown 编辑器。遗留的兼容代码（HTML 格式检测、迁移弹窗、base64 图片迁移上传、HTML 渲染组件等）不再需要。本次修改将完全移除所有老版本兼容逻辑，只保留纯 Markdown 编辑模式。

**图片缩放行为保持不变**：有 width 属性时存储为 `<img src="minio:xxx" width="300">`，无 width 属性时存储为标准 Markdown `![alt](minio:xxx)`。

---

## 七、风险说明

1. **旧版 HTML 文档**：如果服务器上仍存在 Quill 编辑器创建的 HTML 格式文档，移除兼容代码后，这些文档将直接传给 TiptapEditor 以 Markdown 模式解析，可能渲染不正确。如果数据库中还有旧格式文档，建议在移除兼容代码前手动将其迁移。

2. **无数据丢失风险**：所有在 Tiptap 迁移之后创建的文档都是纯 Markdown 格式，不受影响。
